# Security Audit — April 2026

## Overview

VeerTx completed an internal security audit in April 2026 using the OWASP Top 10:2025 framework. The audit was conducted using Claude Code with the owasp-security skill and reviewed by Gemini for architecture sign-off before any fixes were deployed.

## What We Fixed

**C-1 — Content Security Policy hardened**
Removed unused third-party CDN origins from the script-src directive. All JavaScript dependencies are now bundled locally via Vite. Only Cloudflare Turnstile remains as an external script origin, which cannot be SRI-pinned by Cloudflare's own design.

**C-2 — Ghost Memo Telegram injection closed**
The ghost memo feature allows senders to attach an optional private message. This message was previously sent to Telegram with Markdown parse mode enabled, allowing a malicious sender to inject formatted links or break the notification entirely. Fixed by removing Markdown parse mode from receiver DMs — memos now render as plain text only.

**C-4 — Timing-safe webhook comparison**
The Helius USDC webhook secret was compared using !== which is vulnerable to timing side-channel attacks. Replaced with Node's native crypto.timingSafeEqual with proper Buffer conversion and length pre-check.

**H-3 — Chat widget XSS closed**
The support chat widget was rendering streamed AI responses and user input via innerHTML. Replaced with a safe renderSafeText helper that builds DOM nodes explicitly using textContent and createElement — no HTML parsing of user or server content.

**H-5 — Wallet lookup auth gate**
The /api/users/by-wallet endpoint previously returned a VeerTx username for any Solana wallet address with no authentication — creating a surveillance tool that mapped on-chain identities to VeerTx usernames. Fixed by requiring a cryptographic wallet signature on every lookup. The server verifies with nacl.sign.detached.verify before returning any data.

**H-7 — RPC relay origin check**
The /api/rpc Helius proxy endpoint had no origin check, allowing external scripts and bots to use VeerTx infrastructure as a free Solana RPC relay. Fixed by requiring the Origin header to match veertx.com.

## What We Parked

- **H-1** — /api/sol/claimed unauthenticated. Low priority since the endpoint is now primarily a UI state updater with no critical side effects.
- **H-2** — Static claim auth signature with no nonce. Fixing requires a nonce system and DB migration — too large for pre-deadline.
- **H-4** — RELAY_ENCRYPTION_KEY using SHA-256 instead of Argon2. Fixing requires re-encrypting all existing webhook secrets — deferred to V2.
- **C-3** — /internal/payments/create has no API key beyond IP check. The endpoint is localhost-only via Nginx — external exploitation risk is zero. Defense-in-depth improvement deferred.
