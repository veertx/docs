# Security Policy

## Reporting a Vulnerability

To report a security vulnerability in VeerTx, please contact us privately:

- X: @VeerTx (DM)
- Discord: https://discord.gg/tNf5pDVVCe

Do not open a public GitHub issue for security vulnerabilities.

We will respond within 48 hours and work with you on a fix before any public disclosure.

## Audit

VeerTx completed an internal OWASP audit in April 2026. Full report at [security/audit-2026-04.md](security/audit-2026-04.md).

A professional third-party audit is planned pending grant funding.
