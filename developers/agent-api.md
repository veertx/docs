# Private Agent Payments

This is in development.

VeerTx is building private payments for AI agents and applications. The goal: let software make and receive payments without exposing a wallet on-chain - the same privacy the pay links give people today, but for automated systems.

The approach is built on x402, the open standard for machine-to-machine payments over HTTP. An agent calls a paid endpoint, pays through VeerTx, and the payment is routed privately so the agent's wallet and the recipient stay unlinked.

What this will enable:

- AI agents paying for APIs, data, and services privately
- Applications settling payments programmatically, with no custodian
- Per-request micropayments routed through the same privacy layer that powers VeerTx pay links

There is nothing to integrate yet. This page will be updated with real endpoints and integration details when it is ready.
